Arquitectura del Sistema

Este frontend Angular está estructurado bajo las capas de Services, Models, Components y Settings (Guards e Interceptors), comunicándose de forma reactiva con el backend de Spring Boot (R2DBC, SQL Server y Spring Security JWT).

Seguridad basada en Roles (RBAC)

El token JWT entregado por el backend contiene el claim roles: ["ROLE_ADMIN"]. El sistema detecta automáticamente este perfil y redirige de forma transparente al usuario hacia este panel de administración restringido.
